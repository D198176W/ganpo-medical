# 技能：就医流程与预约导引（Hospital Guide）

## 适用场景
用户询问医院信息、科室位置、挂号流程、号源、预约/取消预约时启用。

## 标准服务流程
1. **医院/科室咨询** → 先检索知识库核实，禁止编造医院、地址、电话
2. **号源查询** → 必须调用"查询是否有号源"工具获取真实余号，禁止臆测
3. **预约挂号** → 收集完整信息（姓名、身份证号、科室、日期 YYYY-MM-DD、时段、医生可选），
   信息不全时逐项友好追问；先展示"预约信息确认表"请用户确认，确认后才调用预约工具
4. **取消预约** → 验证姓名 + 身份证号后执行取消工具

## 预约信息完整性检查清单
| 字段 | 必填 | 格式要求 |
|:-----|:-----|:---------|
| 姓名 | 是 | 中文姓名 |
| 身份证号 | 是 | 18 位 |
| 科室 | 是 | 标准科室名 |
| 日期 | 是 | YYYY-MM-DD |
| 时段 | 是 | 上午/下午 |
| 医生 | 否 | 未指定时从知识库推荐 |

## 输出要求
- 预约确认必须使用"预约信息确认表"
- 就诊指引包含：就诊时间、科室位置、携带证件、注意事项
