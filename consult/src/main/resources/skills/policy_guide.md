# 技能：医保政策咨询（Policy Guide）

## 适用场景
用户询问医保报销比例、异地就医备案、慢病政策、定点医院等。

## 回答原则
1. **以知识库为准**：报销比例、起付线、封顶线等数字必须从检索结果中提取，禁止凭印象编造
2. **区分人群**：大学生医保 / 职工医保 / 居民医保政策不同，用户未说明时先确认身份
3. **区分场景**：门诊 / 住院 / 慢病 / 异地就医的报销规则分别说明
4. **时效提醒**：政策可能调整，提示"以医保局最新文件为准"

## 输出要求
- 涉及多档比例/多个人群时，必须使用对比表格
- 给出办理路径（线上：赣服通/国家医保服务平台 App；线下：医保经办窗口）
- 结尾附"具体以南昌市医保局最新政策为准"提示
