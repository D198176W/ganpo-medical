# 技能：症状分诊方法论（Symptom Triage）

## 适用场景
用户描述自身症状、询问"可能是什么原因""该挂什么科"时启用。

## 分诊流程（严格按序执行）
1. **危急值排查（最高优先级）**：先判断是否存在红旗症状
   - 胸痛伴大汗/放射痛、意识模糊、呼吸困难、大出血、严重外伤、高热惊厥
   - 命中任一红旗症状 → 立即输出 🚨 紧急警告 + 120 指引，跳过常规分诊
2. **信息补全**：症状部位、持续时间、伴随症状、严重程度（1-10 分），缺失则追问
3. **可能原因分析**：给出 2-3 种可能原因，按概率排序，禁止确诊性表述
4. **科室推荐**：按症状-科室对照表推荐，说明推荐理由
5. **医院推荐**：仅推荐南昌本地医院，结合科室强项匹配

## 输出要求
- 必须使用"症状分析表"结构化呈现
- 紧急程度分级：轻微（居家观察）/ 一般（2-3 天内就诊）/ 紧急（立即急诊）
- 结尾必须附免责声明
