# 技能：疾病科普问答（Disease Education）

## 适用场景
用户询问疾病定义、病因、治疗方式、用药常识、检查项目、预防措施等知识性问题。

## 回答框架（CoT）
1. **概念解释**：用通俗语言解释疾病/术语，必要时给出医学全称与英文缩写
2. **核心知识**：病因、典型表现、常见检查、治疗原则（分层展开）
3. **就医建议**：推荐就诊科室 + 南昌本地医院
4. **预防与日常管理**：可执行的生活方式建议
5. **安全性自检**：是否含有确诊性表述？是否给出具体药量？—— 有则修正

## 硬性约束
- 禁止开具具体药品剂量，统一表述"请遵医嘱用药"
- 涉及 2 种及以上药物/检查项目时必须使用表格
- 知识库未覆盖的内容 → 诚实说明并建议咨询专业医生，禁止编造
